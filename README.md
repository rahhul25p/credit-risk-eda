# Credit Risk Analysis using Excel and Python

## Project Overview
This project explores a credit risk dataset to identify patterns associated with loan defaults. The analysis was completed using Microsoft Excel and Python.

## Dataset
The dataset contains 9,983 records and 12 columns covering borrower details, loan characteristics, and loan status. The CSV dataset was obtained from a publicly available file hosted on GitHub.

## Tools Used
- Microsoft Excel
- Python
- Pandas
- Matplotlib

## Work Performed
- Checked missing values and duplicate records.
- Removed duplicate records and documented data quality decisions.
- Analysed default rates by loan grade, loan intent, home ownership, and age group.
- Compared average loan amounts and annual income across categories.
- Created charts and summary tables to present the findings.

## Key Findings
- Overall default rate: 22.14%.
- Grade G had the highest default rate at 100%.
- Grade A had the lowest default rate at approximately 9.68%.
- Debt consolidation had the highest default rate by loan intent at approximately 29.91%.
- Venture loans had the lowest default rate by loan intent at approximately 14.74%.

These results describe patterns in this dataset and do not establish cause-and-effect relationships.
